## 1. Configuração do Quality Gate

Foi utilizado o Qodana for JVM Community 2026.2 para realizar
análise estática ao código Java do projeto Battleship2.

### Inspeção selecionada

- Nome: Overly Complex Method
- Identificador: CyclomaticComplexity
- Limite de complexidade ciclomática: 10
- Severidade: High

Esta inspeção identifica métodos com demasiados caminhos
de execução, tornando o código mais difícil de compreender,
testar e manter.

### Condição de falha

No ficheiro `qodana-127523.yaml`, foi configurado:

```yaml
failureConditions:
  severityThresholds:
    any: 6
```

O limite foi definido como 6 porque o projeto já apresentava
seis métodos com complexidade superior a 10.

Assim:
- Até 6 violações: o quality gate passa.
- Mais de 6 violações: o quality gate falha.

Este limite é absoluto, não distingue automaticamente
problemas antigos de novos. Foi escolhido para demonstrar
o funcionamento do quality gate sem modificar o código
existente dos restantes elementos do grupo.

## 2. Validação do Quality Gate

Para validar o funcionamento do quality gate, foi criada
uma branch de teste (`test/qodana-complexity-127523`)
e aberto o Pull Request #30.

### 2.1. Introdução deliberada de um code smell

Foi criada a classe temporária `ComplexityTest127523.java`,
contendo o método `calculateScore()` com 12 instruções `if`.

A complexidade ciclomática calculada foi:

CC = 1 + 12 = 13

Como o limite configurado era 10, o método foi
identificado pela inspeção Overly Complex Method.

O Qodana detetou 7 violações no projeto, ultrapassando
o limite de 6 definido no quality gate.

**Resultado:** Failure (esperado).

**Evidência:**
[GitHub Actions — Quality Gate Failure](https://github.com/LEI-129494/Battleship2/actions/runs/42513668589/job/128831910037?pr=30)

### 2.2. Correção do code smell

Após confirmar a falha, a classe temporária
`ComplexityTest127523.java` foi removida.

O Qodana voltou a executar a análise e o quality gate
passou, uma vez que deixou de existir a violação
introduzida deliberadamente.

**Resultado:** Success (esperado).

**Evidência:**
[GitHub Actions — Quality Gate Success](https://github.com/LEI-129494/Battleship2/actions/runs/42514373431/job/128834071668?pr=30)
