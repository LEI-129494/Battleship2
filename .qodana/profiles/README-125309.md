# Qodana - Long Parameter List

## Regra escolhida
MethodWithTooManyParameters

## Configuração
Foi definido um limite máximo de 5 parâmetros por método.

## Objetivo
Identificar métodos com demasiados parâmetros, reduzindo a complexidade e aumentando a legibilidade do código.

## Limitações
Em alguns casos podem existir métodos legítimos com muitos parâmetros, podendo gerar falsos positivos.
