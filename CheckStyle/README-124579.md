## 1. Regra de nomenclatura

A regra `ConstantName` verifica se os nomes das constantes respeitam um padrão definido.

Foi configurada a seguinte expressão regular no ficheiro `checkstyle-124579.xml`:

```regex
^[A-Z][A-Z0-9]*(_[A-Z0-9]+)*$
```

Esta expressão exige que os nomes das constantes:
- Comecem por uma letra maiúscula;
- Utilizem apenas letras maiúsculas e números;
- Separem palavras com underscores (`_`).

Exemplos:
- Válidos: `MAX_SHIPS`, `BOARD_SIZE`, `NUMBER_SHOTS`;
- Inválido: `maxShips`.

## 4. Limitações

O Checkstyle permite verificar automaticamente se os identificadores respeitam padrões de nomenclatura, mas não consegue determinar se um nome é semanticamente significativo, claro ou adequado à sua finalidade. Além disso, a regra verifica a correspondência com uma expressão regular, não avaliando a qualidade geral do código nem a intenção do programador.
